# Equate Instruments — Product Catalogue

Open product catalogue for [Equate Instruments](https://equateinstruments.com), a dental and orthodontic instrument company designed in Finland.

**Live site:** [ali-amaan.github.io/equate-products](https://ali-amaan.github.io/equate-products/)

## Contents

| File | Description |
|---|---|
| `products.csv` | 3,375 products — SKU, name, family, category, description, materials, specs |
| `products.json` | Same data in JSON |
| `pins/` | 200 watermarked Pinterest Pin images (1000×1500 JPEG) |
| `pins.csv` | Pinterest bulk-upload CSV pointing to the Pin images on this site |
| `pins-part1.csv` | First 100 rows (Pinterest upload limit per batch) |
| `pins-part2.csv` | Remaining 100 rows |
