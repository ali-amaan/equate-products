## Dataset

The full product catalogue is available as structured, machine-readable data.

| File | Format | Description |
|---|---|---|
| [`products.csv`](products.csv) | CSV | 3,375 products — SKU, name, family, category, description, materials, specs |
| [`products.json`](products.json) | JSON | Same data, structured for programmatic use |

### Fields

| Column | Example |
|---|---|
| `Equate_SKU` | EI-0679 |
| `Product_Name` | How Plier 3.2 mm — Max 0.71 mm (028") Wire |
| `Family` | Orthodontic |
| `Category` | Orthodontic Pliers |
| `Subcategory` | Utility Pliers |
| `Slug` | how-plier-3-2mm-max-0-71mm-028-wire |
| `Live_URL` | https://equateinstruments.com/products/orthodontic/how-plier-3-2mm-max-0-71mm-028-wire |
| `Primary_Image_URL` | https://equateinstruments.com/images/products/EI-0679_how-plier-3-2mm_1.webp |
| `Short_Description` | How (Howe) utility plier with 3.2 mm round beaks... |
| `Materials` | Stainless Steel |
| `Specifications` | JSON object with material, coating, wire capacity, etc. |

## Pinterest Pins

200 watermarked product Pin images (1000 × 1500 px, JPEG), ready for [Pinterest bulk upload](https://help.pinterest.com/en/business/article/upload-pins-in-bulk).

| File | Description |
|---|---|
| [`pins/`](pins/) | 200 Pin images hosted on GitHub Pages |
| [`pins.csv`](pins.csv) | Full bulk-upload CSV (200 rows) |
| [`pins-part1.csv`](pins-part1.csv) | First 100 rows |
| [`pins-part2.csv`](pins-part2.csv) | Remaining 100 rows |

Each Pin links back to its product page on [equateinstruments.com](https://equateinstruments.com). Media URLs point to `ali-amaan.github.io/equate-products/pins/`.
